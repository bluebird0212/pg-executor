Bluebird PG

手机安装页 · 点几下就能用

1安装 Tampermonkey（已装可跳过）
打开 Tampermonkey 官网
Android 推荐用 Firefox、Kiwi 或 Cromite；Chrome 本身不支持扩展。
2安装 Bluebird PG 脚本
安装 / 更新脚本
如果出现 “This page is used as an intermediate step…” 页面，等它自动关闭；没反应就打开 Tampermonkey → 添加新脚本，把脚本内容粘进去保存。
3打开 AI Studio
打开临时会话页
登录 Google 后，页面右下角会出现 Bluebird PG 面板。
4连接本地服务（推荐用电脑跑）
电脑双击 bluebird-pg.exe，手机和电脑连同一个 Wi-Fi。面板地址填 http://电脑局域网IP:8090，再点「复制主机 / 复制 Key」填到客户端。
下载 Windows 服务
没有电脑？完全在手机上运行（Termux） 
pkg install -y curl
curl -fsSL https://raw.githubusercontent.com/bluebird0212/pg-executor/main/termux.sh | bash
会自动安装 Ubuntu + Python 依赖，首次需要几百 MB；旧手机需要保持 Termux 在后台运行。
